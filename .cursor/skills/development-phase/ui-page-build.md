# UI Page Build Skill

When building a page or screen:

## Process
- Define the page goal.
- Identify required sections and actions.
- Reuse existing layout and UI patterns.
- Build for clarity first.
- Add loading, empty, error, and success states where relevant.
- Keep actions visible and consistent.

## Typical Deliverables
- page structure
- components
- forms if needed
- actions
- validation feedback
- list/table behavior if applicable

## Blade Rules

- Do not place business logic inside Blade templates.
- Keep Blade for presentation only.

## Data Flow

- UI must not perform business logic.
- All data must come from backend services or controllers.
