# Backend Feature Implementation Skill

## Purpose
Implement backend logic for a feature following Laravel architecture rules.

---

## Process

### 1. Validation
- Create Form Request
- Define rules clearly

---

### 2. Service Layer
- Create Service class
- Implement business logic
- Keep logic reusable

---

### 3. Controller
- Keep thin
- Call service only

---

### 4. Database Interaction
- Use models correctly
- Respect relationships
- Avoid N+1

---

### 5. Error Handling
- Handle:
  - validation
  - business errors
  - not found

---

## Rules Enforcement

- No logic in controller
- No validation in controller
- No direct DB logic in views

---

## Output Format

- Form Request
- Service class
- Controller method
- Model usage
- Error handling
